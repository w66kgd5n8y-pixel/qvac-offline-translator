# QVAC Offline Text Translator

An open-source, local-first text translation application powered by Tether's `@qvac/sdk`. All model inference runs strictly on-device without external API calls or internet dependence.

## SDK Version
- `@qvac/sdk`: `^0.19.0`

## Requirements
- Node.js >= 22.17.0
- npm
